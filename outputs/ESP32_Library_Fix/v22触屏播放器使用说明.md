# v22.0 触屏播放器使用说明

本版将常用操作移到指南者 240×320 电阻触摸屏，保留网页作为辅助入口。v20.9、v21 的完整源码目录均保留。

## 更新两端

1. Keil 打开 `../STM32_Touch_Console/Project/Player_v22.uvprojx`，编译并下载。
2. Arduino 打开本目录 `ESP32_Touch_Console.ino`，编译并上传。
3. Arduino 配置保持：ESP32S3 Dev Module、16MB Flash、OPI PSRAM、Huge APP，端口选择实际识别的 COM。
4. 两板重新上电。两板 UART 230400、SPI 2MHz、电脑串口监视器 115200；接线保持不变。
5. 本版屏幕协议已改变，必须更新两端，不能混用 v21/v20.9 的单端程序。
6. 触摸位置不准时，按住指南者 K1 和 K2 再按 RESET，按照屏幕十字校准。本次校准仍只在本次上电期间有效。

已沿用 v20.9 的 Keil 调试选项文件；FireDAP 若再次连接失败，检查 CMSIS-DAP、SW、Connect under Reset。

## 触屏布局

- 顶栏左侧「随声」：刷新当前曲库。
- 顶栏中间：音量；右侧「登录」：显示酷狗扫码登录二维码。
- 三个曲库标签：「在线」「喜欢」「本地」。
- 曲库每页 **8 首**，底部「上页 / 播放页 / 下页」翻页或切换播放页。
- 在线搜索最多保留 **16 首**结果，继续仅排除需单独付费的项目、保留 VIP。
- 内存卡仍读取根目录前 **128 首** MP3 / WAV，不扫描子目录。
- 点击曲目会进入独立播放页：两行标题、逐行同步歌词、进度条、已播放/总时长。
- 底部固定「上首 / 暂停或播放 / 下首」，以及「减音 / 播放模式 / 加音 / 停止」。

`触屏曲库预览.png`、`触屏播放页预览.png`、`触屏检索预览.png` 由固件实际绘制函数离线渲染，使用示例内容，不是硬件实测照片。

## 连续播放

点击底部模式按钮循环切换：

| 模式 | 播完后的行为 |
| --- | --- |
| 顺序 | 自动下一首；在线当前结果集、本地当前列表末尾回到开头。喜欢列表按页继续读取 |
| 单曲循环（按钮显示「循环」） | 播完后重新播放当前曲目 |
| 单首停止 | 播完停止，点击下一首仍可手动切歌 |

本地检索启用时，自动切换按已筛选的本地列表进行。读取或解码失败会停止并显示提示，避免反复尝试失败曲目。跨歌曲可能有获取地址、歌词或读取文件的等待时间；本版不承诺无缝切歌。

## 不依赖网页选歌

### 本地

1. 点击「本地」。未读取过列表时会读取卡。
2. 点击左上角「随声」可重新读取。
3. 点击「上页 / 下页」浏览，点击歌曲播放。
4. 再次点击已选中的「本地」标签，打开屏幕键盘，可用英文、数字过滤文件名；清空输入后点击「搜索」恢复全部列表。
5. 键盘上的中文快捷词也可用于本地筛选。

### 在线

1. 点击「在线」，再次点击进入屏幕键盘。
2. 输入英文或数字关键词，点击「搜索」。键盘「返回」回到列表。
3. 也可以点击「小苹果 / 小星星 / 轻音乐 / 钢琴」中文快捷词。
4. 本版没有完整中文拼音输入法；任意中文关键词仍可由保留的网页或串口输入。

### 酷狗我喜欢

1. 点击右上角「登录」，用酷狗 APP 扫描开发板二维码并确认。
2. 登录成功后自动请求「我喜欢」；也可手动点击「喜欢」。再次点击当前「喜欢」标签会重新同步。
3. 每页读取 8 首，屏幕翻页、点击播放，播放结束可按页继续。
4. 云端请求仍取决于登录会话、平台接口及账号播放权限；失败时屏幕给出提示并保留已有曲目。

### 离线

Wi-Fi 连接失败后，本地触屏播放仍可使用；启动时的连接等待最多约 30 秒。配置文件 Wi-Fi 信息为空时也可进入本地操作。在线搜索、酷狗登录和在线歌词需要网络。

## 进度条与定位

- 进入播放页，在进度条区域点击，或拖动后**松手**，提交目标位置。
- MP3 当前采用从文件开头重新解码、跳过目标之前音频的办法，保持解码器连续状态，兼容变码率及位储存依赖。
- 因此，跳到较远位置会等待读卡/下载与解码，屏幕显示「正在定位」。本版不是字节范围随机快跳。
- 定位后恢复播放；若此前暂停，定位操作也会恢复播放。
- 本地 WAV 使用直接文件定位，响应更快。
- 进度读取 STM32 的音频采样消耗计数，不按网络下载速度推算；DAC 半缓冲准备及屏幕刷新仍会带来少量显示延迟。
- 优先使用歌曲元数据或 MP3 Xing/Info 帧数确定总时长；缺少这些信息时按码率估算，总时长前显示 `~`。估算时长及定位百分比可能有偏差。

## 歌词

### 本地同名 LRC

把歌曲和同名 `.lrc` 文件放在 TF 卡根目录，例如：

```
阿桑 - 温柔的慈悲.mp3
阿桑 - 温柔的慈悲.lrc
```

- 必须是 **UTF-8 编码**的带时间标签 LRC，支持 UTF-8 BOM；暂不支持 GBK、KRC 和 ID3 内嵌歌词。
- 支持 `[mm:ss]`、`[mm:ss.x]`、`[mm:ss.xx]`、`[mm:ss.xxx]`、一行多个时间标签和 `[offset:±毫秒]`。
- 当前最多读取 32KB、保留 256 条时间标签，每条文字最多 127 字节；超长内容会截断。
- 播放页显示当前歌词，可自动换行；本版是逐行同步，不是逐字卡拉 OK。
- 无文件、无有效时间标签或超出字库的特殊字符可能显示提示/替代字符。

已提供 `../audio_test/test.lrc`。将它与已有的 `test.mp3` 一起复制到卡根目录，可以先测试本地歌词，不必依赖酷狗云端。

### 在线歌词

播放网络曲目前，ESP32 通过歌曲 hash/歌曲信息向酷狗歌词服务查询并请求 LRC。服务未提供 LRC、请求失败或无有效内容时显示「暂无同步歌词」，仍继续播放音乐。接口尚需使用用户账号与实际歌曲上板验证。

## 建议验收顺序

1. 本地 `test.mp3` 连续播放，确认音频、暂停、音量、上一曲/下一曲正常。
2. 把 `test.lrc` 放在卡上，确认 2 秒、4 秒等位置的歌词会切换。
3. 播放本地大 MP3，连续听一分钟，再测试进度条；远距离定位时等待「正在定位」结束。
4. 顺序模式下观察歌曲结束自动下一曲；再测试单曲循环与单首停止。
5. 检查 8 行分页点选不串曲、检索清空后恢复列表。
6. 最后测试登录、酷狗「我喜欢」、在线音乐与在线歌词。

若卡顿，请发 `SD_UNDERRUN`、`Local MP3 transfer failed` 或 `UI update not confirmed` 附近日志。不要发送 Wi-Fi 密码、账号 token 或二维码密钥。

## 检查状态

- STM32 编译结果记录于版本更新日志，Flash/RAM 未超出 STM32F103VE 规格。
- ESP32 语法与 Arduino 整包编译通过：程序 1438795 / 3145728 字节（45%），全局变量 77156 / 327680 字节（23%）。
- 触屏实际事件函数的分页、索引、进度边界与 QR 返回测试通过。
- 共用 UART 分包/交错行接收测试通过。
- 实际 MP3 解码器的 5 秒定位输出与完整解码对应数据对照通过；Xing 与码率时长计算测试通过。
- 顺序、单曲循环、单首停止、本地筛选顺序和喜欢列表跨页切换测试通过。
- LRC 时间标签、偏移、排序、BOM、容量限制测试通过。
- 实际 LCD 绘制函数离线渲染检查通过，所有像素位于 240×320 范围。
- 尚未上板实测；v20.9 仍是此前用户确认正常的音频基线。新显示、定位、云端与连续播放需完成上述验收。
