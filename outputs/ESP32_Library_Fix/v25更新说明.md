# v25 界面交互、音量与 MP3 原文件下载

需要两个开发板一起更新。Arduino 核心使用当前已安装的 esp32 3.3.12。接线、16MB Flash、OPI PSRAM、Huge APP 3MB 配置保持不变；触摸校准数据兼容 v23/v24。

## 工程入口

- STM32：`STM32_Interaction_Fix/Project/Player_v25.uvprojx`。
- ESP32：`ESP32_Interaction_Fix/ESP32_Interaction_Fix.ino`。
- 关闭旧 Arduino 项目再打开本目录；启动显示 `Player interaction fixes v25.0`，两端就绪提示 `STM32 v25 ready; calibration complete`。

## 这版改动

### 页面切换

- 播放页点击“在线 / 喜欢 / 本地”，统一进入对应的缓存列表；重复点当前分类同样返回列表，不再当作检索或刷新。
- 这些分类切换保留当前播放歌曲，各分类记录列表页码。
- “当前播放”仅切换页面，不再通过新歌曲指令把进度和歌词状态清零。
- 浏览列表时自动进入下一首，保持列表浏览状态；明确点歌才进入播放页。
- 提示信息使用独立提示页，并提供“返回列表”，防止提示盖住歌曲后仍能点到看不见的行。
- 播放过程中优先使用缓存；喜欢列表尚未同步时，重读工作延后到当前播放停止，以避免网络同步阻塞供音频。本版未实现所有网络任务与播放并行。
- 主动刷新、在线搜索和扫码登录仍可能中止播放；本次主要修复分类按钮与返回逻辑。

### 键盘

- 顶部“检索”开关键盘；再次点击关闭，返回原分类列表。
- 输入后点“搜索”立即收起键盘，再进行检索。
- 排布为数字 `1234567890`、`qwertyuiop`、`asdfghjkl`、`zxcvbnm`；后两行错位对齐。
- 底部提供退格、空格、清空、搜索；保留四个中文快捷词。
- 修正文字右边界判断：`p`、`9` 等右侧字符不会被统一按双字节宽度裁掉。

### 音量

- 原先松开任何按钮会重绘整页，改为只恢复按下边框。
- 音量数字变化只重绘数字区域；加减音量不再强制进行整组界面同步。
- ESP32 MP3 与 STM32 本地 WAV 均加入约20–32ms的固定点增益过渡，减少音量突变产生的点击声。
- 播放采样率与 SPI 音频握手保持原来配置；是否消除实机破音仍需听测。

### 歌词 TLS -10368

- 已从安装的 mbedTLS 头文件确认：`-10368 = -0x2880 = MBEDTLS_ERR_X509_ALLOC_FAILED`，表示证书处理内存分配失败。
- 原来把完整 PEM 根证书集合传给 setCACert，改用 Arduino 3.3.12 的 `useBuiltinCACertBundle()`。该核心已启用完整证书包；保持证书和域名验证，不使用 setInsecure。
- 歌词、网络音频和新增 MP3 下载均使用该内置验证方式；搜索/账号网关的原有独立证书设置不变。
- 需要实机重新获取歌词确认；如果仍失败，提供 `LRC` 错误日志。

## 云端下载 MP3 到板载 TF

1. 从“在线”或“喜欢”选择能够取得播放链接的歌曲。
2. 进入播放页，点击“下载”。当前播放停止，开始将云端 MP3 原文件保存到 TF；网页原有下载按钮也使用同样流程。
3. 等待提示下载完成，再点“返回列表”并进入“本地”。文件名为 `M00001.MP3`、`M00002.MP3` 等自动编号；不会覆盖同名文件。暂不保存原歌曲名或内嵌歌词。
4. 点击新文件本地播放，仍由 ESP32 解码，STM32 负责读卡和输出。

原文件不转码、不受播放音量影响；最后不足512字节按实际大小写入。ESP32/STM32对完整长度和CRC做一致性检查，通过后才从 `.TMP` 改名为 `.MP3`。下载中断、存储失败或校验失败不会发布为歌曲；残留TMP可稍后用电脑清理。

仅支持返回已知长度、无额外HTTP编码的MP3响应，遇到其他音频格式明确拒绝保存。不会绕过付费权限；云端未提供歌曲链接时不能下载。现有曲库仍最多显示根目录128首。

## 验证

- STM32完整重编译：0错误、0警告；ESP32最终完整构建通过：Flash40%、静态RAM23%，最终编译副本与交付源码一致。
- 真实触摸处理函数：按下/松开、拖出取消、分类返回、p/9、键盘关闭、搜索收起、下载触摸通过。
- 真实ESP32页面处理函数：浏览不停止歌曲、分类页码恢复、当前播放不重置、显式点歌/下载停止旧播放通过。
- 实际绘图函数和字体生成键盘/播放页预览，像素均在240×320范围内；这是软件渲染预览，不是实机照片。
- 真实存储函数测试：513字节MP3精确保存、CRC通过后发布、失败与未完成不发布；保留旧WAV协议兼容性。
- 音量过渡单调、边界无溢出、静音与满音量端点检查通过；真实MP3解码及短/快速定位测试通过。
- 所有功能仍需用户上板验收，不能把编译/本机测试等同于硬件验证。
