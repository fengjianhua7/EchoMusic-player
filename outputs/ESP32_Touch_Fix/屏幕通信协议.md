# v22 屏幕与音频协议补充

保持 SPI 音频包 512 字节、Mode 0、2MHz、READY 握手；保留 v20.8 修正的片选事务边界。两板 UART 230400。

## ESP32 到 STM32（逐条等待 UI_OK）

- `LB:来源:页码:总数:本页数量:还有下页`：来源 0 在线、1 喜欢、2 本地；页码从 0 开始；每页最多 8 行。
- `LT:行号:UTF8十六进制标题`：填充本页一行，行号从 0 开始。
- `NP:UTF8十六进制标题`：进入播放页。
- `PG:位置毫秒:时长毫秒:暂停:音量:模式:估算标记:定位中:起始偏移毫秒:播放中`：进度/控制状态。回应 `UI_OK:已消耗PCM采样数`。
- `LY:UTF8十六进制歌词`：显示当前歌词。
- `MSG:UTF8十六进制提示`：显示操作提示。
- `S:状态文本`：常用状态，v22 增加 UI_OK 应答。
- `Q:边长:点阵十六进制`：沿用二维码协议，回应 QR_OK。

注意 PG 实际按代码为 9 个数值字段：位置、时长、暂停、音量、模式、估算、定位中、起始偏移、播放中。

## STM32 到 ESP32

- `UI:SOURCE:来源`、`UI:PAGE:±1`、`UI:PLAY:来源:分页索引`。
- `UI:NOW`、`UI:LIST`、`UI:REFRESH`。
- `UI:SEARCH:关键词`、`UI:PRESET:0..3`。
- `UI:SEEK:0..1000`、`UI:MODE`、`UI:PREV`、`UI:STOP`。
- 保留 `P`、`N`、`+`、`-`、`L` 及实体按键事件。

所有接收路径共用半包缓冲，读卡命令等待与 UI 等待均派发触摸事件，避免事件被其他应答读取路径丢弃。

## 存储命令补充

- `C`：清空音频队列和播放采样计数，回应 SD_CLEARED。
- `LC:索引`：查找同名 LRC，按 SD_LRC:十六进制块输出，最终 SD_LRC_END；最大 32KB。
- `J:毫秒`：本地 WAV 定位，回应 SD_SEEK:OK。
- WAV 打开成功回应 `SD_PLAYING:时长毫秒`。
- `G:音量` 新增 SD_VOLUME 应答。

播放采样计数由 DAC 循环 DMA 半缓冲填充时累计有效音频采样，清空队列时归零；这不是墙钟计时，也不统计欠载时输出的静音。
