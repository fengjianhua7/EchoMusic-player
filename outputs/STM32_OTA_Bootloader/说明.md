# 第二阶段：ESP32-S3 到 STM32 的 SPI 音频测试

本阶段替换 STM32 main.c，ESP32 产生 1kHz 测试音，STM32 不再自行产生测试音。
第一阶段 main.c 备份为 User/main_dac_test.c.txt（不要加入编译）。
尚未编译及上板验证，不包含 Wi-Fi、MP3 解码或 EchoMusic 接口。

## 断电后接线

ESP32 GPIO12 -> STM32 PB13（SPI2 时钟）
ESP32 GPIO11 -> STM32 PB15（SPI2 MOSI）
ESP32 GPIO10 -> STM32 PB12（SPI2 NSS 片选）
ESP32 GPIO9  <- STM32 PB0（READY）
ESP32 GND   -- STM32 GND

两块板各自使用 USB 供电，不要互接 5V 或 3V3。
GPIO 编号不是排针序号。音频输出仍使用原来的 PA4 隔直衰减电路。
连接前确认 PB0、PB12、PB13、PB15 未被其他模块驱动；不用 TF 卡及外接 SPI2 模块。
需要核对具体板原理图和跳帽，若存在共用外设，应断开其片选或相关跳帽。

## 操作

1. Keil 打开 Project/BH-F103.uvprojx，Rebuild 并下载 STM32。
2. Arduino 打开 ../ESP32_SPI_Audio/ESP32_SPI_Audio.ino，开发板保持 ESP32S3 Dev Module。
3. 上传 ESP32 程序。串口监视器选择 115200。
4. 如传输等待或超时，先按 STM32 RESET，再按 ESP32 RST。
5. 接通音箱，小音量试听，预期持续 1kHz 音调。
6. 断开 ESP32 数据源后，STM32 缓冲播放完应转为静音；这是区分本地测试音的检查。

## 协议和限制

SPI 模式0，1MHz，ESP32 主机，STM32 SPI2 从机。
每块256个采样（512字节），32kHz、单声道、有符号PCM16、小端。
STM32 READY 为高后，ESP32 拉低 NSS 发送一块，并保持 NSS 低直到 READY 变低。
STM32 等待 NSS 回高，再重新使能接收 DMA；空间不足则延迟 READY。
STM32 使用4096采样环形缓冲，DAC双半缓冲，每半256采样。
欠载输出2048中点。当前协议是固定长度实验协议，无校验、序号及超时重同步，传输中复位需重启两端。
后续加入错误恢复和网络解码。当前不要修改采样率或块大小，否则两端会失配。
