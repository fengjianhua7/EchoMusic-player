# v27 本地曲库与进度条定位修复

适用：已安装v26引导程序和ESP32双程序分区。此次只更新ESP32与STM32应用，**不需要重新下载引导程序，也不改分区表或触摸校准区**。无线升级包格式仍兼容v26。

## 更新方法

1. 打开现有 `/upgrade` 页面，进入升级模式并输入屏幕上的升级码。
2. 选择ESP32，上传本目录 `ESP32_v27.ota.bin`，等待重启完成。
3. 再进入升级模式，选择STM32，上传 `STM32_v27.stmfw`，等待写入和重启完成。
4. 停止播放后点“本地”，让曲库重新读取。

若仍用数据线：ESP32工程为 `ESP32_Library_Fix/ESP32_Library_Fix.ino`，Flash16MB/OPI PSRAM/Custom分区；STM32为 `STM32_Library_Fix/Project/Player_v27.uvprojx`，仍是0x08008000应用，选择Erase Sectors。不要整片擦除引导程序。

## 本地只有一首的处理

- 目录逐条打印到115200调试串口可能拖住230400板间串口的接收；取消逐首文件名镜像日志，只保留扫描和数量摘要。
- 板间串口接收缓冲由默认小缓冲增加为8KB。
- 新增STM32列举数量报告；ESP32先接收到暂存列表，收到完整结束及数量一致才一次性更新，避免静默显示丢行后的残缺列表。
- 列表接收异常时保留原显示并提示重读，暂停使用不确定的文件索引，不把残缺索引当成有效曲库。
- 明确点击“本地”会清除旧筛选并返回第一页；未播放时重新读卡，播放中使用缓存以避免打断歌曲。
- 本地列表左上显示当前总曲数，便于区分“只显示本页”和“只加载一首”。

这些修正针对已发现的接收/筛选问题，不等于已在你的卡上确认唯一根因。扫描范围仍是根目录MP3/WAV、最多128首，未完成下载仍隐藏，旧TMP没有删除。

如果更新后仍少歌，请提供串口这三行：

- `SD_SCAN:条目数:文件夹数:非支持项目数:未完成项目数:列出歌曲数`
- `SD_LIST_COUNT:...`
- `TF list loaded: songs=...`

这样可区分目录扫描、串口传输和界面筛选问题，无需先格式化或移动文件。

## 本地进度条定位

- 本地MP3定位保留当前文件句柄，直接调整读卡位置；不再中途关闭/重开歌曲、重绘停止页、输出结束统计。
- 常见音乐的解码预热从约2秒缩短到约0.5秒，仍保留帧同步和位储备预热。
- 多次拖动使用循环重启解码，不递归叠加调用。
- 新增 `Local seek: target=... offset=... warmup=...` 与 `Seek first PCM: ... ms after decoder restart`，用于实测定位阶段耗时。
- 定位仍为近似位置，不是采样精确；SD卡读取性能、文件码率和VBR映射仍影响实际速度，不承诺固定毫秒数。
