# v21.0：界面、本地搜索与酷狗「我喜欢」

## 更新方法

1. Keil 打开 `../STM32_Music_Library/Project/Player_v21.uvprojx`，编译并下载到指南者。
2. 关闭 Arduino 旧工程，不保存旧内容；打开本目录 `ESP32_Music_Library.ino`。
3. Arduino 保持 ESP32S3 Dev Module、16MB Flash、OPI PSRAM、Huge APP；选择实际 COM 端口后上传。
4. 两板重新上电。电脑串口监视器保持 **115200**；两板内部通信仍为 **230400**，SPI 仍为 **2MHz**。
5. 手机连接相同 Wi-Fi，打开串口显示的 `Phone control` 地址。此前是 `http://192.168.1.209`，以当前 IP 为准。
6. 若网页仍是旧布局，关闭该页重新打开，或刷新浏览器缓存。

现有接线保持不变。v20.9 的两个完整源码目录保留在原位置，可回退；不要只保留一个旧 uvprojx，因为同目录工程共用源码。

## 新界面

- 手机网页分为「在线搜索」「我喜欢」「内存卡」，底部固定播放、下一首、停止和音量控制。
- 顶部显示当前选择/播放的歌曲名和状态。
- 开发板常用触摸按钮改为中文，并翻译常用播放、暂停、搜索、结束状态。
- `界面预览.png` 为使用示例歌曲数据的布局预览，不是设备实测截图。

## 本地搜索

1. 进入「内存卡」，点击「读取列表」。这会停止正在进行的本地播放以便扫描。
2. 输入歌曲名或歌手名，列表即时过滤，清空关键词恢复全部列表。
3. 搜索结果仍使用原始文件索引播放，不会因过滤后的位置变化而播放其他歌曲。
4. 当前读取 TF 卡**根目录前 128 首 MP3/WAV**；搜索范围就是这份列表。不递归子目录，不搜索音频内部标签，也不支持拼音检索。
5. 网页仅在列表变化时重新获取完整本地列表，避免每两秒重复传输 128 首文件名。

## 酷狗「我喜欢」

1. 沿用已保存的酷狗登录。未登录时，点击「扫码登录」，扫描开发板二维码并在酷狗 APP 确认。
2. 打开「我喜欢」，点击「同步列表」。ESP32 直接向酷狗读取该账号的歌单，并识别「我喜欢」「我喜欢的音乐」「默认收藏」「喜欢的音乐」。
3. 每页读取 5 首，支持上一页、下一页。歌单目录最多查找前 300 个项目。
4. 点击「播放」，这页歌曲同步到开发板歌曲列表，继续使用已有播放链路。
5. 切换账号会清除设备内存中的喜欢列表缓存；不会修改或删除酷狗云端收藏。
6. 云端请求失败或响应字段无法识别时，保留上一页。明确标记为需单独购买的曲目被过滤，VIP 项目保留；能否完整播放仍取决于账号权限及音频格式。
7. 本次接口按公开上游实现移植，尚未用用户账号上板验证。若同步失败，请发 `API /v7/get_all_list` 或 `API /v4/get_list_all_file_v3` 附近日志，不要发送 token、密码或二维码密钥。

当前只做读取和播放，不提供添加、删除收藏功能；喜欢列表不持久化到 TF 卡。
