# 网络音乐播放器 v27 源码与资料包

本文件夹已集中放入 v27.0 的完整交付内容。

## 文件夹说明

- `源码/ESP32_Library_Fix`：ESP32-S3 主程序，Arduino IDE 打开 `ESP32_Library_Fix.ino`。
- `源码/STM32_Library_Fix`：STM32F103 应用程序，Keil 打开 `Project/Player_v27.uvprojx`。
- `源码/STM32_OTA_Bootloader`：STM32 无线升级引导程序，仅首次安装或维护引导程序时使用。
- `资料与固件/Wireless_Update_v27`：局域网无线升级需要的 ESP32 与 STM32 固件及说明。
- `资料与固件/版本更新日志.md`：版本变更和验证状态。
- `项目源码与资料总览.md`：架构、接线、编译方法、限制和源码阅读入口。

## 开始前

ESP32 的 `config.h` 已替换为不含个人信息的模板。请填写自己的 Wi-Fi 名称和密码后再编译；不要把填好后的文件公开分享。

当前 v27 针对本地曲库和定位作了改进，但仍需要实际硬件验收。请使用已备份的测试 TF 卡，原先出现歌曲丢失的卡不要继续作为写入测试卡。
