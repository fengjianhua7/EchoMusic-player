# 网络 MP3 测试版

STM32 固件和接线不变。Arduino 打开 ESP32_Network_MP3.ino。
config.h 保留原来的 Wi-Fi 设置，MP3_URL 指向 http://192.168.1.164:8000/test.mp3。
若Wi-Fi设置为空，请仅在本地填写。不要分享包含密码的config.h。
开发板 ESP32S3 Dev Module，使用原COM端口，PSRAM可以保持Disabled。
本程序使用SET_LOOP_TASK_STACK_SIZE(32768)增大解码栈，适用于当前已安装的Arduino ESP32 3.3.x。
内置 minimp3.h，不需要通过库管理器安装解码库。

上传后打开115200串口监视器，联网成功后发送小写p。
预期显示 HTTP status: 200、MP3采样率及声道数，听到测试音阶。
当前仍由电脑临时提供文件，不能在电脑关闭时访问此测试链接。

实现：MP3逐帧解码，双声道混为单声道，基础采样率转换至32kHz，按原SPI协议发送。
当前采样率转换采用简单保持/抽样，无抗混叠滤波，仅用于功能验证。
16KB压缩缓冲；网络读取与播放串行，可能因网络抖动断音。
仅支持HTTP直链、200响应、明确Content-Length；不支持HTTPS、重定向、chunked或平台登录。
尚未接入EchoMusic接口，不支持暂停、切歌及中途采样率变化。
保留原SPI协议约束，传输中复位或ACK超时后需重启两端。

验证：已检查代码完整性、名称及缓冲边界，未在本环境完成Arduino编译或硬件测试。
解码库来源：https://github.com/lieff/minimp3，许可证随附LICENSE.minimp3。
