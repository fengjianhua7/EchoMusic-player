# v15：屏幕列表与按键播放器

原先可用的扫码/播放工程保持不变，本版本为新副本。
先下载STM32_Player_Control/Project/BH-F103.uvprojx，再上传ESP32_Player_Control/ESP32_Player_Control.ino。
接线完全沿用：SPI五线、ESP17到B11、B10到ESP18，板载Wi-Fi两个跳帽拔下，PA4音频电路不变。
Arduino仍选择ESP32S3 Dev Module，原COM口，Huge APP分区。config.h从上一版复制。

## 使用

已保存登录会话时，开机会自动搜索“小苹果”，屏幕显示最多5首候选与选择箭头。
只排除明确付费购买的PayType=2，保留VIP和未知标记结果，不保证每个VIP版本可被当前会话播放。

K1短按：未播放时选择下一项；播放时停止当前并尝试播放下一项。
K2短按：未播放时播放选中项；播放中暂停，再按恢复。
K1长按至少1秒再松开：停止播放，切换到下一组预设搜索。
预设顺序：小苹果、小星星、轻音乐、钢琴，循环。
K2长按至少1秒再松开：停止播放，打开扫码登录。

无会话时，长按K2扫码；手机确认后，短按K2加载第一组歌曲。
按键事件在松手时触发，不需要一直按住。
任意关键词仍可从电脑串口发送 s 歌曲名，随后屏幕同步列表。
当前不含触摸输入法；这版电脑不参与音乐接口/解码，开机和常用操作可用按键完成。

## 验证与限制

STM32工程已在本机Keil编译：0错误、0警告；Code=10192、RO-data=245620、RW-data=132、ZI-data=14204字节。
新增6763个16x16汉字点阵，使用内部Flash，不要求外置字库或SD卡；屏幕状态/按键提示暂为英文。
本环境尚未完成Arduino编译；整个v15控制交互尚未上板验证。
列表最多检查20个候选，最多显示5项，长歌名会被截断。
暂停会停止继续向STM32送数据，已缓冲的声音可能再持续约0.15秒。
暂停期间服务器可能关闭连接，长时间暂停后可能需要重新选择播放；尚未实现断点续传。
网络请求期间按键响应可能延迟，最大受网络超时限制；当前没有独立网络下载任务。
基础32kHz单声道重采样、MP3格式限制及接口变化风险沿用上一版。
目前播放中不处理电脑串口命令，使用板上K1/K2控制。
账号令牌仍保存在ESP32 Preferences，不应分享config.h；切勿启用整片Flash擦除以免丢失会话。

## 验证顺序

1. 编译下载STM32新工程，屏幕能点亮。
2. 上传ESP32，重启，确认Player buttons and screen v15，等待自动搜索。
3. 查看中文列表；K1改变箭头，K2播放。
4. K2暂停/恢复；K1尝试下一首。
5. 长按K1切换搜索；最后验证长按K2扫码。
有编译错误先发日志，不用先调整接线或清空会话。
