# v18 稳定性改进

基于v17新增：后台Wi-Fi重连、16项控制命令队列、音量和播放模式记忆、上次搜索词记忆。
手机页新增单曲播放/列表循环/单曲循环/随机播放模式。
播放模式仅在正常播放结束时自动继续；失败时停止，避免反复请求不能播放的版本。
搜索会替换列表，播放请求携带列表版本，防止旧页面点错歌曲。
停止会清除待处理命令和待搜索任务。
音量/模式/搜索词在停止或暂停超过3秒后保存，避免播放时频繁写Flash。
突然断电发生在保存前，会保留上一次已保存设置。
断网后停止当前音频并尝试重连，不自动从断点恢复歌曲。
手机页显示失败提示；不代表已实现完整异步网络架构。

STM32继续使用v16，接线不变。Arduino使用ESP32S3 Dev Module、Huge APP、16MB Flash。
