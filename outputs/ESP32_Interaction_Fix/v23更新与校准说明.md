# v23.0 修复版：校准、按下反馈、本地加载、快速定位和歌词

## 先更新两块板，再进行四点校准

1. Keil 打开 `../STM32_Touch_Fix/Project/Player_v23.uvprojx`，下载到指南者。
2. Arduino 打开本目录 `ESP32_Touch_Fix.ino`，上传到 ESP32-S3。
3. 两端一起重新上电。接线、SPI 2MHz、两板 UART 230400、电脑串口 115200、16MB Flash / OPI PSRAM / Huge APP 均保持不变。
4. **第一次启动会显示十字。依次按住每个十字约 0.2～0.5 秒，然后松开，共 4 次：三个校准点加一个中心验证点。**
5. 中心验证偏差过大时会重新开始，请按十字中心；不要按屏幕文字。ESP32 等待校准完成是正常现象。
6. 合格的校准结果保存到 STM32 片内 Flash，下次重启直接使用。串口可见 `CAL_SAVED:1`；如果是 0，说明本次 RAM 校准有效，但未保存成功。
7. 需要重新校准时，按住 K1 和 K2，再按 STM32 RESET；看到十字后松开按键，完成校准，然后重新启动 ESP32。

两端必须都是 v23；ESP32 会等待 `UI_READY:23`，防止校准过程中提前发送读卡命令。原 v20.9、v21、v22 完整源码目录保留。

## 触摸位置与按下反馈

- 不再依赖某一块板子的固定触摸变换系数。
- 按下有效按钮显示**橙色边框**，松开恢复并执行。
- 滑出按钮后松开会取消；轻微抖动保持最初落点，避免松手瞬间位置漂移导致误触。
- 拖动进度条时显示橙色预览，松开后提交定位。
- 翻页/切换内容发生在手指按住期间时，松开不会触发旧页面的曲目。
- 顶栏现在分为：左侧「随声」刷新、中间「检索」打开键盘、右侧「登录」。
- 点击「本地」明确重读内存卡，不再把本地标签的再次点击当作打开键盘。

`按下反馈预览.png` 来自实际固件绘制逻辑的离线渲染，不是硬件照片。

## 本地歌曲优先验证

- 校准和握手完成后，**自动读取内存卡列表**，不先联网搜索。
- Wi-Fi 改为后台连接；本地读取与播放不等待 Wi-Fi 或网络时间同步。
- 启动/重读前显式停止旧文件并重置未完成 SPI 接收，恢复 ESP32 单独重启或上次中断留下的状态。
- 点击「本地」或左上角「随声」可重读；该操作会停止当前播放。
- 正常情况下串口会出现 `TF list loaded: songs=N`，界面显示曲目数量。
- 仍只读卡根目录前 128 首 MP3/WAV；子目录里的歌曲不会出现在这份列表。
- 挂载、打开目录、枚举目录失败会显示 `MOUNT:数字` / `LIST:数字` / `READDIR:数字`，不再把枚举失败误当作空目录。
- 无歌曲会明确提示「根目录未找到 MP3/WAV」。失败时可以再次点击本地重试；不会自动格式化或删除音乐。

**如果仍读不到，优先发屏幕的完整错误或 `SD_ERR` / `TF list loaded` 附近日志，暂时不需要测试快进。**

## 快速定位

- CBR MP3 按码率定位到目标前约 2 秒；有 Xing TOC 的 VBR 使用索引，无 TOC 时使用时长/文件大小近似。
- 本地直接跳转文件位置；在线使用 HTTP Range，并复用当前歌曲短期播放地址。
- 只重新解码短预热区，不再从头把目标之前所有音频重读一遍。
- 这是**近似定位**；变码率无 TOC、元数据不准或帧重新同步可能带来偏差，界面会标记估算。
- 目标接近开头时仍从头解码，但只需很短前缀。
- 在线来源不支持 Range / 206 时会提示不支持快速定位，不回退到长时间扫描；可以重新开始播放。
- 加入定位解码与网络连接超时，避免一直停在「正在定位」。实际耗时仍受 Wi-Fi 与读卡速度影响。
- WAV 保留直接文件定位。

## 网络歌词修复

已确认并修正两处问题：

1. 旧 `/v1/search` 在本次公开接口测试中返回 HTTP 200、但正文为空；改用 `/search`。
2. 相同测试请求的 HTTP/1.0 返回 418，HTTP/1.1 返回正常 JSON；歌词请求改为 HTTP/1.1，并设置客户端请求头。

其他改动：

- 按 hash 查询无结果时，可按歌曲信息重试；优先请求 LRC。
- 请求失败不作为成功结果缓存，重播会重新尝试。
- 串口记录搜索候选数、返回字节数和解析行数，不输出账号 token、歌词访问密钥或歌词正文。
- 本地同名 UTF-8 LRC 优先；没有本地 LRC 时，已联网的情况下按歌曲文件名在线查找。文件名检索可能匹配到不同版本。
- `test.mp3`、`test1.wav`、自动编号的 M000xx 文件不按无意义文件名搜索网络歌词；可继续搭配 `../audio_test/test.lrc` 测试。
- 刚联网、网络时间尚未同步时会提示等待同步后重播；不阻止本地音频播放。
- 2026-11-03 的只读公开测试已完成搜索、LRC 下载，并用固件同一解析代码识别出 44 行定时歌词；未输出或保存歌词正文作为交付物。

这不代表已验证所有歌曲或板上的 TLS/网络环境。无匹配歌词时音乐仍可播放。

## 校准存储说明

适用于本项目的 STM32F103VE（512KB Flash）：最后 2KB、地址 `0x0807F800` 留给校准配置，链接器程序区为 `0x08000000` 起、长度 `0x7F800`。已检查应用链接起址与保留页边界。

校准只在通过中心验证后写入，带版本、屏幕尺寸和校验。Keil 使用整片擦除时会清除校准，下次启动需再做四点校准；扇区擦除正常下载可保留。
