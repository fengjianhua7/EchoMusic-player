# v17：手机局域网控制

STM32继续使用v16 STM32_Touch_Player固件，接线不变，仅上传新的ESP32_Phone_Player.ino。
Arduino开发板、COM口和Huge APP分区沿用原设置，config.h已复制。
此版基于v16；如果v16触摸尚未验证，可先测试手机功能，STM32仍需v16以支持音量等控制。

## 使用

1. 上传后，手机与ESP32连同一个家庭Wi-Fi。
2. 用手机浏览器打开串口输出的 Phone control 地址，例如 http://192.168.1.209/。
3. 部分手机支持 http://stm32music.local/，无法打开时使用IP地址。
4. 输入中文歌曲名或歌手，点击搜索，等待结果更新。
5. 点击对应歌曲播放。页面支持播放/暂停、下一首、停止、音量加减。
6. 点击扫码登录时，二维码显示在STM32屏幕，用手机酷狗APP扫一扫。
7. 手机网页不显示或传输账号token，也不提供登录二维码，账号仍由ESP32保存。
8. 页面仅排除明确付费购买版本，保留VIP歌曲。

电脑仅用于上传、调试，手机控制页和音频服务都在ESP32本机；电脑可在上传完成后关闭。
仍需为两块板分别提供稳定USB电源，不能因为关电脑而切断供电。

## 当前限制

请求在局域网内直连ESP32，无云端转发，没有公网访问配置。
网络歌曲接口请求与播放仍在同一主循环，搜索/授权期间页面可能暂时不响应，稍后会自动重试刷新。
播放/暂停与音量指令在播放服务点处理；网络读取超时可能造成延迟。
播放时网页刷新可能造成抖动，本阶段未加入独立下载/解码任务及PCM队列。
暂停后服务器可能关闭音频连接，暂不支持断点续传。
点击搜索会停止当前音频，随后进行新搜索；新搜索会替换当前列表。
设备当前只保留最新一个待处理控制命令，请勿快速连续点击多个操作。
会话存在不等于会话有效；页面“已登录”表示本地有会话，实际授权失败需重新扫码。
仅在同一局域网使用；尚未添加网页配对密码和多用户权限，未配置路由器端口转发。
